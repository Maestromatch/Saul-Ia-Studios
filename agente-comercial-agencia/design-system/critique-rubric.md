# Rubrica de Critica Visual 5D - IAStudio

Inspirada en `nexu-io/open-design` y su skill `critique`.

## Uso

Aplicar antes de cerrar una landing, demo, dashboard, deck o pieza visual importante.

Cada dimension se puntua de 0 a 10 con evidencia concreta. No promediar para esconder fallas graves.

## 1. Filosofia

Pregunta:
- La pieza tiene una direccion clara y consistente?

Evidencia:
- Tono visual.
- Paleta.
- Tipo de layout.
- Microcopy.
- Relacion con la marca o cliente.

Bandas:
- 0-4: mezcla estilos sin criterio.
- 5-6: direccion entendible, pero elementos se desvian.
- 7-8: coherente, con detalles por ajustar.
- 9-10: cada decision refuerza la tesis visual.

## 2. Jerarquia

Pregunta:
- Se entiende que leer primero, segundo y tercero?

Evidencia:
- H1 y CTA.
- Tamanos de texto.
- Orden de secciones.
- Peso de cards/paneles.
- Uso de labels y metadata.

Bandas:
- 0-4: todo compite.
- 5-6: hero funciona, interior flojo.
- 7-8: lectura clara.
- 9-10: recorrido visual sin friccion.

## 3. Detalle

Pregunta:
- La ejecucion se siente pulida?

Evidencia:
- Spacing.
- Alineacion.
- Bordes.
- Estados hover/focus.
- Caracteres especiales.
- Copy sin errores.
- Componentes consistentes.

Bandas:
- 0-4: se ven costuras.
- 5-6: funcional, pero con asperezas.
- 7-8: profesional con ajustes menores.
- 9-10: listo para cliente exigente.

## 4. Funcionalidad

Pregunta:
- Cumple su trabajo real?

Evidencia:
- CTA WhatsApp.
- Responsive.
- Tabs o interacciones.
- Formularios.
- Accesibilidad.
- Datos y proximo paso.

Bandas:
- 0-4: se ve bien pero no sirve.
- 5-6: flujo principal sirve, bordes fallan.
- 7-8: robusto para uso normal.
- 9-10: defensivo, probado y claro.

## 5. Innovacion

Pregunta:
- Tiene un elemento memorable que sume al objetivo?

Evidencia:
- Demo interactiva.
- Visualizacion clara del sistema.
- Motion sutil.
- Layout distintivo.
- Forma nueva de mostrar valor.

Bandas:
- 0-4: generico.
- 5-6: competente pero olvidable.
- 7-8: un detalle memorable y pertinente.
- 9-10: distintivo sin sacrificar claridad.
