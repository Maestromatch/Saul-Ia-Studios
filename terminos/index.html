Terminos y Condiciones

Estos terminos regulan el uso del sitio y la contratacion de servicios de Aetria Studio relacionados con sistemas IA, automatizacion comercial, CRM, WhatsApp, Meta Ads, landing pages y gestion de leads.

1. Servicios

Aetria Studio presta servicios de diagnostico, configuracion, implementacion y optimizacion de sistemas comerciales digitales. Los servicios pueden incluir bot WhatsApp, CRM, landing pages, Meta Ads, Google Business, automatizaciones, contenido y seguimiento comercial.

2. Alcance de cada proyecto

El alcance especifico, precio, plazos, entregables, datos requeridos y criterios de terminado deben definirse antes de iniciar cada servicio. Cualquier trabajo adicional no incluido en el alcance original puede cotizarse por separado.

3. Informacion entregada por el cliente

El cliente debe entregar informacion veraz, accesos, materiales, fotos, textos, datos comerciales y autorizaciones necesarias para ejecutar el servicio. Retrasos en la entrega de informacion pueden modificar plazos.

4. Datos personales y leads

Si el servicio involucra datos personales o leads de terceros, el cliente declara contar con autorizacion o base legitima para su tratamiento. Aetria Studio tratara esos datos solo para ejecutar el servicio contratado, conforme a la Ley 19.628 y la Politica de Privacidad publicada.

5. Herramientas de terceros

Algunos servicios dependen de plataformas externas como Meta, Google, WhatsApp, Vercel, CRM, n8n, hojas de calculo u otras herramientas. Aetria Studio no controla cambios, bloqueos, caidas, politicas o decisiones de esas plataformas.

6. Resultados comerciales

Aetria Studio no garantiza ventas cerradas, ingresos, cantidad especifica de leads ni resultados economicos determinados. El compromiso es implementar, medir y optimizar el sistema acordado segun el alcance contratado.

7. Pagos

Los servicios pueden requerir pago inicial, anticipo o pago por etapas. Los costos de terceros, pauta publicitaria, dominios, herramientas, licencias o suscripciones no estan incluidos salvo que se indique expresamente.

8. Propiedad y uso de entregables

Una vez pagado el servicio, el cliente puede usar los entregables acordados para su operacion comercial. Aetria Studio puede conservar plantillas, aprendizajes, metodologias y componentes genericos no confidenciales para mejorar sus servicios.

9. Confidencialidad

Aetria Studio tratara con reserva la informacion interna, comercial, tecnica o de clientes finales que reciba para ejecutar un servicio. El cliente tambien debe resguardar accesos, credenciales y materiales entregados.

10. Cambios y cancelaciones

Los cambios de alcance, pausas, cancelaciones o reprogramaciones deben acordarse por escrito. Si existe trabajo ya ejecutado, este puede descontarse del monto pagado o cobrarse segun avance.

Estos terminos se rigen por las leyes de la Republica de Chile, incluyendo la Ley 19.628 cuando exista tratamiento de datos personales.
