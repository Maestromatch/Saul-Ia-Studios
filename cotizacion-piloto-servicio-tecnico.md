# Cotizacion - Pack IA Express para Servicio Tecnico

## Saul IA Studios

**Servicio:** Implementacion piloto de IA para recepcion y orden de solicitudes tecnicas.  
**Plazo:** 5 a 7 dias habiles desde recepcion de antecedentes y anticipo.  
**Validez de cotizacion:** 7 dias.

## Objetivo

Implementar un flujo simple para que el negocio pueda responder preguntas frecuentes, capturar datos importantes del cliente y ordenar solicitudes tecnicas en una planilla/CRM basico.

## Alcance del piloto

### 1. Diagnostico express
- Revision del proceso actual de atencion.
- Identificacion de preguntas frecuentes.
- Definicion del flujo inicial de captura.

### 2. Flujo IA / asistente inicial
- Respuestas para preguntas frecuentes.
- Captura de datos clave:
  - Nombre.
  - Telefono.
  - Comuna.
  - Tipo de equipo.
  - Marca/modelo si aplica.
  - Falla reportada.
  - Urgencia.

### 3. Registro de solicitudes
- Planilla CRM simple.
- Estados sugeridos:
  - Nuevo.
  - Contactado.
  - Diagnostico agendado.
  - Cotizado.
  - Aprobado.
  - Cerrado.
  - Perdido.

### 4. Mensajes de seguimiento
- Mensaje para confirmar diagnostico.
- Mensaje para enviar cotizacion.
- Mensaje para recuperar cliente sin respuesta.

### 5. Capacitacion
- Sesion de 60 minutos.
- Entrega de instrucciones de uso.
- 7 dias de ajustes menores.

## No incluido

- Desarrollo de software a medida fuera del alcance definido.
- Costos de herramientas externas si el cliente solicita una plataforma pagada.

## Condicion de exito del piloto

El piloto se considera entregado cuando:
- El flujo de atencion inicial esta definido.
- La planilla/CRM esta creada.
- Los mensajes de seguimiento estan listos.
- El cliente recibe capacitacion.
- Se prueban al menos 3 casos simulados o reales.
