# Agente Comercial — Saul IA Studios

> Agente interno de la agencia para buscar, filtrar, responder y convertir prospectos.

## Objetivo

Construir un sistema comercial propio para Saul IA Studios:

**Prospeccion -> Conversacion -> Calificacion -> Diagnostico -> Propuesta -> Cierre -> Seguimiento**

## Principio

El agente no vende "IA".  
El agente detecta problemas de negocio y propone el primer paso correcto.

## Que debe lograr

- Encontrar prospectos con dolor real.
- Personalizar mensajes.
- Ofrecer mini-servicios cuando el prospecto no esta listo.
- Escalar a Pack IA Express o Sistemas de Captacion cuando hay dolor fuerte.
- Agendar diagnosticos.
- Registrar todo en CRM.
- Aprender que nicho/mensaje/oferta convierte mejor.

## Archivos

- `01-icp.md`: cliente ideal y no ideal.
- `02-ofertas-entrada.md`: mini-servicios y paquetes que el agente puede ofrecer.
- `03-crm-estados.md`: pipeline comercial.
- `04-scripts-prospeccion.md`: mensajes por canal.
- `05-objeciones.md`: respuestas a objeciones comunes.
- `06-prompt-maestro.md`: identidad y reglas del agente.
- `07-playbook-nichos.md`: constructoras, opticas, servicios tecnicos y otros.
- `08-casos-prueba.md`: pruebas antes de conectar a WhatsApp.
- `crm-prospectos-agencia-template.csv`: plantilla CRM.
- `learning-log-comercial.md`: memoria compuesta.

## Regla de oro

Si el prospecto no puede pagar o no entrega datos, no se fuerza venta grande. Se ofrece mini-servicio o se descarta con respeto.
