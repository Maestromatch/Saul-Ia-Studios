Politica de Privacidad

Esta politica describe como Aetria Studio trata datos personales en el contexto de servicios de automatizacion comercial, CRM, formularios, WhatsApp, Meta Ads, landing pages y gestion de leads.

1. Responsable del tratamiento

Aetria Studio es responsable del tratamiento de los datos personales que recibe directamente a traves de sus formularios, WhatsApp, correo, reuniones comerciales o canales digitales propios.

2. Datos que podemos tratar

Podemos tratar datos de contacto y datos comerciales necesarios para responder consultas, preparar diagnosticos, ejecutar servicios y mantener relacion comercial. Estos datos pueden incluir nombre, telefono, correo, empresa, rubro, comuna, cargo, fuente del lead, historial de conversaciones, estado comercial y necesidad declarada.

3. Datos de leads de terceros

Cuando un cliente contrata a Aetria Studio para implementar CRM, formularios, bots WhatsApp, landing pages o sistemas de captacion, los datos de leads pertenecen al cliente contratante. Aetria Studio actua como proveedor tecnico y operacional, tratando esos datos solo para prestar el servicio acordado.

4. Finalidades

Los datos pueden usarse para responder solicitudes, preparar diagnosticos, ejecutar servicios contratados, configurar automatizaciones, registrar oportunidades en CRM, medir campanas, mejorar procesos, emitir comunicaciones comerciales relacionadas y cumplir obligaciones legales o contractuales.

5. Base legal y Ley 19.628

El tratamiento de datos personales se realiza conforme a la Ley 19.628 sobre Proteccion de la Vida Privada de Chile y demas normativa aplicable. Aetria Studio procura tratar solo datos necesarios, pertinentes y proporcionales a la finalidad informada.

6. Encargados y herramientas

Para prestar servicios podemos usar herramientas de terceros como CRM, plataformas de automatizacion, Meta, Google, WhatsApp, Vercel, servicios de correo, hojas de calculo y otras aplicaciones tecnicas. Estas herramientas se usan con fines operativos y bajo configuraciones razonables de seguridad.

7. Conservacion

Los datos se conservan durante el tiempo necesario para cumplir la finalidad para la cual fueron recolectados, mantener trazabilidad comercial, prestar soporte, cumplir obligaciones legales o resolver solicitudes pendientes. Un cliente puede solicitar eliminacion o actualizacion cuando corresponda.

8. Derechos de las personas

Las personas pueden solicitar acceso, rectificacion, cancelacion, oposicion o eliminacion de sus datos personales cuando proceda conforme a la Ley 19.628. Para ejercer estos derechos, pueden escribir a Aetria Studio por WhatsApp o al canal de contacto informado en la web.

9. Seguridad

Aetria Studio aplica medidas razonables para proteger los datos contra acceso no autorizado, perdida, alteracion o uso indebido. Ningun sistema es infalible, pero se trabaja con criterio de minimizacion, permisos necesarios y separacion de credenciales sensibles.

10. Cambios

Esta politica puede actualizarse cuando cambien los servicios, herramientas o exigencias legales. La version publicada en este sitio sera la vigente.

Ultima actualizacion: 21 de mayo de 2026.
