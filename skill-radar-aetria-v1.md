# Skill Radar AetriaStudio

> Proceso interno para integrar nuevas skills sin convertir la agencia en una caja de herramientas desordenada.

## Que cambio

Se instalo `find-skills` desde `vercel-labs/skills`. Esta skill sirve para descubrir skills del ecosistema antes de construir algo desde cero.

Tambien quedaron visibles skills relacionadas con:

- revision de diseño web;
- UX;
- HyperFrames;
- video desde website;
- animacion GSAP/WAAPI/Lottie/Three;
- Tailwind para composiciones;
- ideacion de productos.

## Para que le sirve a AetriaStudio

### 1. Antes de crear una oferta nueva

Buscar si existe skill para acelerar:

- propuestas comerciales;
- auditorias de negocio;
- landing local;
- SEO;
- dashboards;
- automatizaciones;
- contenido;
- video.

### 2. Antes de construir una landing

Usar `review-web-design` como checklist:

- jerarquia visual;
- color;
- tipografia;
- responsive;
- CTAs;
- consistencia de marca.

### 3. Antes de vender video/contenido

Evaluar `website-to-hyperframes` + `hyperframes`:

- reel desde una landing;
- video de propuesta;
- demo de servicio;
- anuncio corto;
- tour visual de un sistema.

### 4. Antes de instalar automatizaciones

Buscar skills n8n, CRM, WhatsApp, Supabase, seguridad o testing.

## Protocolo

1. Identificar la necesidad.
2. Buscar skill con `find-skills` o revisar skills instaladas.
3. Leer `SKILL.md` antes de usarla.
4. Revisar fuente, reputacion y permisos.
5. Probar en local, nunca directo en produccion.
6. Si sirve, documentar:
   - que problema resuelve;
   - para que servicio aplica;
   - riesgo;
   - siguiente prueba;
   - si se vuelve SOP, oferta o herramienta interna.

## Regla de seguridad

No ejecutar skills desconocidas con datos de clientes, API keys, WhatsApp, Meta, Supabase o n8n sin revisar primero.
