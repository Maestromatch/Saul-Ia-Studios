# Checklist Ejecucion Diaria - Aetria Studio

## Antes de contactar

- [ ] Elegir nicho del dia.
- [ ] Elegir oferta de entrada.
- [ ] Revisar CRM para no repetir prospectos.
- [ ] Preparar 1 mensaje base.
- [ ] Preparar 1 observacion concreta por prospecto.

## Prospectos

- [ ] Revisar 15 negocios.
- [ ] Guardar nombre.
- [ ] Guardar rubro.
- [ ] Guardar comuna.
- [ ] Guardar canal visible.
- [ ] Registrar dolor probable.
- [ ] Definir servicio sugerido.

## Contacto

- [ ] Enviar 10 mensajes personalizados.
- [ ] No mandar discurso largo.
- [ ] Pedir permiso para enviar observacion.
- [ ] Registrar estado en CRM.

## Si responde

- [ ] Preguntar dolor principal.
- [ ] Confirmar canal principal: WhatsApp, Instagram, Google, llamadas o formulario.
- [ ] Preguntar si registra leads.
- [ ] Preguntar si hace seguimiento.
- [ ] Ofrecer Diagnostico IA Express si hay dolor.

## Cierre

- [ ] Explicar precio: desde $29.000 CLP.
- [ ] Explicar entrega: 24 a 48 horas.
- [ ] Pedir datos basicos.
- [ ] Registrar pago pendiente o agendado.
- [ ] Definir proximo paso.

## Seguimiento

- [ ] Revisar conversaciones de ayer.
- [ ] Enviar seguimiento 24h.
- [ ] Enviar seguimiento 72h.
- [ ] Cerrar los que no respondan sin insistir demasiado.

## Aprendizaje

- [ ] Que mensaje funciono?
- [ ] Que nicho respondio?
- [ ] Que objecion aparecio?
- [ ] Que oferta genero interes?
- [ ] Que debo mejorar manana?
