# Plan Operativo Aetria Studio V1

## Norte

Aetria Studio sera una agencia IA boutique en Santiago enfocada en implementar sistemas comerciales conectados para PYMEs y constructoras: Meta Ads, landing, bot WhatsApp, CRM, seguimiento, contenido y medicion.

La marca debe sentirse premium, pero vender cosas concretas. No somos una consultora fria ni una agencia de marketing generica. Somos implementadores de sistemas IA para captar, responder y ordenar oportunidades.

## Fase 1: Marca y base digital

**Objetivo:** que Aetria se vea confiable antes de contactar clientes.

Acciones:
- Cerrar logo final.
- Revisar favicon y OG image.
- Ajustar paleta para que no se vea seca: negro editorial, crema, verde profundo y acento cobre/dorado.
- Definir bio Instagram y WhatsApp Business.
- Definir frase principal: "Agencia IA boutique para WhatsApp, CRM y Meta Ads".

Entregables:
- Landing SEO.
- Logo y assets.
- Bio y descripcion corta.
- Links WhatsApp por servicio.

## Fase 2: Landing SEO + conversion

**Objetivo:** que la web posicione y convierta.

Acciones:
- Mantener keywords principales: agencia IA Santiago, bot WhatsApp Chile, CRM WhatsApp, Meta Ads constructoras, automatizacion ventas Chile.
- Reforzar servicios visibles.
- Agregar mas muestras visuales del sistema.
- Hacer que el texto sea premium, pero entendible para una PYME.
- Evitar exceso de lenguaje abstracto como "infraestructura digital" sin explicar que gana el cliente.

Entregables:
- Landing final Aetria.
- Schema SEO actualizado.
- CTA por servicio.

## Fase 3: Catalogo comercial

**Objetivo:** tener una vitrina clara para vender sin explicar todo desde cero.

Servicios base:
- Diagnostico IA Express.
- Auditoria WhatsApp.
- Bot WhatsApp + CRM.
- Setup Identidad Meta Legal.
- Landing Express.
- Pack IA Express.
- Sistema de Captacion para Constructoras.
- Content Engine IA.
- Ads Growth Management.

Cada servicio debe explicar:
- Para quien es.
- Que problema resuelve.
- Que incluye.
- Que gana el cliente.
- Precio desde.
- Plazo.
- CTA WhatsApp.

## Regla de decision

Cada accion de Aetria debe mejorar una de estas tres cosas:

- Confianza.
- Claridad de compra.
- Capacidad de entrega.
