# IAStudio - Kit de lanzamiento

Este kit es la primera mision: salir a vender un piloto real con una oferta simple, demostrable y cobrable.

## Nombre recomendado

**Saul IA Studios**

Por que:
- Mantiene "IA Studio", que te tinca.
- Tiene identidad personal, directa y defendible desde tu historia.
- Suena implementador, cercano y profesional sin quedar generico.
- Permite crecer hacia pymes de toda la zona sur de Santiago y luego Chile.

Alternativas:
- **Nexo IA Studio**: mas corporativo y flexible.
- **Impulso IA Studio**: mas comercial, enfocado en crecimiento.

- **SurIA Studio**: mas territorial, menos personal.

Decision operativa para piloto: **Saul IA Studios**.

## Promesa

Instalamos IA y automatizaciones simples para que pymes respondan mas rapido, ordenen sus clientes y dejen de perder ventas por falta de seguimiento.

## Oferta piloto

**Pack IA Express para Pymes**

Precio fundador:
- Entrada: **$250.000 CLP**
- Precio ideal: **$350.000 CLP**
- Precio si incluye landing + bot + automatizacion: **$450.000 CLP**

Condicion de cobro:
- 50% anticipo para comenzar.
- 50% contra entrega.

Entrega:
- 5 a 7 dias.

Incluye:
- Diagnostico express del proceso comercial.
- Mini landing o formulario de captacion.
- Bot/asistente basico para respuestas frecuentes.
- Planilla CRM simple para ordenar leads.
- Automatizacion basica: lead capturado, alerta y seguimiento.
- Capacitacion de 60 minutos.
- 7 dias de ajustes.

No incluye:
- Campanas pagadas.
- Integraciones complejas con sistemas privados.
- Desarrollo de software a medida extenso.
- Soporte ilimitado.
