# Integracion Aetria - Agente Desarrollo Personal

## Ubicacion

Modulo incrustado en raiz:

`agente-desarrollo-personal/`

## Proposito

Este modulo queda como capa de desarrollo personal y patrones del fundador. No reemplaza al agente comercial ni a la landing. Sirve para:

- detectar bucles de energia, foco y ejecucion;
- ordenar compromisos personales de 24-48h;
- convertir aprendizaje personal en disciplina operativa;
- sostener consistencia cuando la agencia entra en presion comercial.

## Uso dentro de la mente de agencia

Antes de decisiones importantes, revisar:

- `agente-desarrollo-personal/prompts/system.md`
- `agente-desarrollo-personal/docs/arquitectura.md`
- `agente-desarrollo-personal/docs/seguridad.md`

## Reglas

- No usar este modulo para inventar citas, diagnosticos o promesas.
- No mezclar datos sensibles personales con archivos publicos de clientes.
- No subir audios, transcripciones, embeddings ni bases SQLite si contienen informacion privada.
- El modulo se puede versionar como estructura y codigo, pero los datos personales deben quedarse fuera del repo publico.

## Relacion con Aetria Studio

Aetria vende sistemas comerciales. Este modulo sostiene al operador/fundador:

- claridad;
- energia;
- foco;
- seguimiento de compromisos;
- deteccion de patrones repetidos.

La agencia gana cuando el fundador ejecuta con estabilidad.
