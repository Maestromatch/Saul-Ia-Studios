# Carpeta `clientes/`

Aquí vive todo el trabajo operativo de cada cliente del Pack IA Express.

## Cómo usar

1. **Copia** la carpeta `_PLANTILLA-CLIENTE/` y renómbrala con el nombre comercial del cliente en kebab-case:
   - Ejemplo: `_PLANTILLA-CLIENTE/` → `optica-buona-visione/`
2. Abre la carpeta del cliente. Cada archivo es una **hoja de trabajo lista para llenar** — no documentación.
3. Sigue el orden de carpetas: `01-onboarding/` → `02-construccion/` → `03-entrega/` → `04-testimonio/`.
4. Cuando termines el piloto, deja la carpeta como caso de estudio (sirve para empacar el OS futuro).

## Privacidad

Las carpetas de clientes contienen datos confidenciales (RUT, precios, FAQ propias, número WhatsApp Business). Están excluidas del repo público vía `.gitignore`. **Solo se sube `_PLANTILLA-CLIENTE/` y este README.**
