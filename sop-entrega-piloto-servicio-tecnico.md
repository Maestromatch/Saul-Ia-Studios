# SOP de implementacion - Piloto servicio tecnico

## Fase 1 - Preparacion

Entrada:
- Anticipo recibido.
- Onboarding completado.
- Accesos o enlaces necesarios.

Acciones:
- Crear carpeta del cliente.
- Crear copia del CRM template.
- Definir version del paquete: basico, recomendado o completo.
- Revisar tono y reglas de respuesta.

Salida:
- Alcance confirmado.
- Preguntas frecuentes clasificadas.

## Fase 2 - Diseno del flujo

Crear flujo base:

1. Saludo.
2. Identificacion del tipo de equipo.
3. Captura de falla.
4. Captura de comuna.
5. Captura de nombre y telefono.
6. Derivacion a humano.
7. Registro del caso.

Reglas:
- No prometer reparacion.
- No dar diagnostico definitivo.
- No inventar precios.
- Derivar urgencias o casos ambiguos.

## Fase 3 - Construccion

Entregables:
- Base de respuestas.
- CRM simple.
- Landing/formulario si aplica.
- Mensajes de seguimiento.
- Mini dashboard si aplica.

Pruebas:
- Caso notebook no enciende.
- Caso celular mojado.
- Caso consola sin imagen.
- Caso cliente pregunta precio sin datos.
- Caso fuera de zona.

## Fase 4 - Capacitacion

Explicar:
- Como revisar nuevos casos.
- Como cambiar estados.
- Como responder seguimientos.
- Como reportar fallas del flujo.
- Que puede y no puede hacer la IA.

## Fase 5 - Cierre

Checklist final:
- [ ] Flujo probado.
- [ ] CRM creado.
- [ ] Mensajes listos.
- [ ] Cliente capacitado.
- [ ] 7 dias de ajustes explicados.
- [ ] Pago final solicitado.
- [ ] Testimonio pedido.
