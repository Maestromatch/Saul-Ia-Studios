# Modelo operativo de agencia — Saul IA Studios v1

## Vision

La agencia opera como una fabrica de sistemas IA para pymes locales.

La agencia tambien opera como un sistema de aprendizaje compuesto: cada repositorio, cliente, error o servicio nuevo debe convertirse en memoria, SOP o activo reutilizable.

Cada cliente debe pasar por:

1. Diagnostico.
2. Oferta.
3. Implementacion.
4. Captacion.
5. Seguimiento.
6. Optimizacion.
7. Caso de estudio.

## Areas internas

### 1. Strategy

Define:
- Nicho.
- Oferta.
- Pricing.
- Promesa.
- Riesgos.

### 2. Build

Implementa:
- Landing.
- Bot.
- CRM.
- Dashboard.
- Automatizaciones.

### 3. Growth

Ejecuta:
- Meta Ads.
- Google Business.
- Contenido organico.
- Retargeting.
- Prospeccion propia de la agencia.

### 4. Content

Produce:
- Posts.
- Reels.
- Carruseles.
- Creativos Ads.
- Testimonios.

### 5. Ops

Controla:
- QA.
- Seguimiento.
- Reportes.
- Learning log.
- SOPs.
- Memoria progresiva.
- Verificacion por evidencia.

## Producto minimo por cliente

No aceptar cliente sin:

- Responsable de responder leads.
- Oferta clara.
- Fotos o informacion real.
- Canal de contacto.
- Capacidad de tomar decisiones.

## Cliente ideal

- Tiene servicio probado.
- Atiende por WhatsApp.
- Pierde leads por desorden.
- Puede pagar setup.
- Tiene margen para recuperar inversion.
- Quiere crecer, no solo "probar IA".

## Cliente no ideal

- No tiene oferta clara.
- No responde.
- Quiere todo gratis.
- Solo busca el precio mas bajo.
- No entrega datos.
- No permite medir.

Cada cliente debe tener:

- Onboarding.
- SOP build.
- QA.
- Ads/Growth si aplica.

## Manual del creador

Saul debe usar `manual-creador-servicios-saul-v1.md` como guia operativa para ejecutar cada servicio sin improvisar:

- calificar cliente,
- elegir servicio correcto,
- cobrar,
- pedir datos,
- construir,
- hacer QA,
- entregar,
- pedir testimonio,
- documentar aprendizaje.

## Regla de aprendizaje compuesto

Cada cliente debe dejar:

- 1 SOP mejorada.
- 1 plantilla reutilizable.
- 1 objecion resuelta.
- 1 insight de mercado.
- 1 pieza para portafolio.

Si no queda aprendizaje documentado, la agencia no escala.

## Protocolo de memoria

Antes de ejecutar cambios relevantes:

1. Leer `memory/observations-index.md`.
2. Abrir solo el detalle necesario.
3. Si toca UI, revisar `design-system/MASTER.md`.
4. Ejecutar.
5. Verificar con evidencia.
6. Registrar aprendizaje si aplica.

Documento rector:
- `protocolo-memoria-y-verificacion-agencia.md`

## Agente comercial interno

El sistema comercial propio vive en:

`agente-comercial-agencia/`

Uso:
- buscar prospectos,
- filtrar clientes,
- vender mini-servicios,
- agendar diagnosticos,
- alimentar CRM,
- documentar objeciones,
- mejorar mensajes.

Este agente se debe usar antes de crear campañas o prospectar manualmente para mantener consistencia.
