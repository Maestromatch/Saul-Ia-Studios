# Demo piloto - Servicio tecnico

## Contexto

Negocio: servicio tecnico de computadores, celulares o electrodomesticos.  
Problema: solicitudes desordenadas, datos incompletos y cotizaciones repetitivas.

## Conversacion demo

Cliente:
Hola, mi notebook no enciende. ¿Cuanto sale revisar?

IA:
Hola. Podemos ayudarte. Para orientar bien el caso, ¿que marca es el notebook y en que comuna estas?

Cliente:
HP, estoy en San Bernardo.

IA:
Gracias. ¿El equipo no prende nada, prende luces o llega a mostrar imagen?

Cliente:
No prende nada.

IA:
Entendido. El diagnostico permite revisar cargador, placa, bateria y conector. Te puedo dejar registrado para que un tecnico confirme disponibilidad. ¿Nombre y telefono?

Cliente:
Marco, 9 8888 7777.

IA:
Listo, Marco. Quedaste registrado: notebook HP no enciende, comuna San Bernardo. El equipo te contactara para coordinar diagnostico.

## Lo que pasa por detras

El sistema registra:
- Nombre: Marco.
- Telefono: 9 8888 7777.
- Comuna: San Bernardo.
- Equipo: notebook HP.
- Problema: no enciende.
- Estado: nuevo diagnostico.
- Proximo paso: contactar para coordinar.

## Mensaje de cierre de demo

El tecnico recibe datos utiles desde el primer contacto y no tiene que preguntar lo mismo una y otra vez.
